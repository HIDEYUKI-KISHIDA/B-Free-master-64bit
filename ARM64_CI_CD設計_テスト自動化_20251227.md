# ARM/64 OS テスト自動化・CI/CD設計（2025/12/27）

---

## 1. テスト自動化方針
- userland_arm/ 配下の各テスト（API, device, process, mmu, fs, power, shell, peripheral など）を自動ビルド・自動実行
- build_armtest/Makefile で一括ビルド・クリーン
- テスト結果は標準出力・ログファイルに記録
- CI/CD（例: GitHub Actions）でプルリク/マージ時に自動テスト

---

## 2. サンプルMakefile（build_armtest/Makefile）
```makefile
CC=gcc
CFLAGS=-I../kernel_arm -I../userland_arm

all: net_api_testcases api_sample device_test_arm process_test_arm mmu_test_arm fs_test_arm power_test_arm shell_test_arm peripheral_test_arm

net_api_testcases: ../userland_arm/net_api_testcases.c ../kernel_arm/net_arm.c
	$(CC) $(CFLAGS) -o $@ $^
api_sample: ../userland_arm/api_sample_arm.c ../kernel_arm/net_arm.c ../kernel_arm/device_arm.c
	$(CC) $(CFLAGS) -o $@ $^
device_test_arm: ../userland_arm/device_test_arm.c ../kernel_arm/device_arm.c
	$(CC) $(CFLAGS) -o $@ $^
process_test_arm: ../userland_arm/process_test_arm.c ../kernel_arm/process_arm.c
	$(CC) $(CFLAGS) -o $@ $^
mmu_test_arm: ../userland_arm/mmu_test_arm.c ../kernel_arm/arch/mmu_arm.c
	$(CC) $(CFLAGS) -o $@ $^
fs_test_arm: ../userland_arm/fs_test_arm.c ../kernel_arm/fs_arm.c
	$(CC) $(CFLAGS) -o $@ $^
power_test_arm: ../userland_arm/power_test_arm.c ../kernel_arm/power_arm.c
	$(CC) $(CFLAGS) -o $@ $^
shell_test_arm: ../userland_arm/shell_test_arm.c ../kernel_arm/shell_arm.c
	$(CC) $(CFLAGS) -o $@ $^
peripheral_test_arm: ../userland_arm/peripheral_test_arm.c ../kernel_arm/fs_arm.c ../kernel_arm/uart_arm.c ../kernel_arm/power_arm.c ../kernel_arm/net_extra_arm.c
	$(CC) $(CFLAGS) -o $@ $^

clean:
	rm -f net_api_testcases api_sample device_test_arm process_test_arm mmu_test_arm fs_test_arm power_test_arm shell_test_arm peripheral_test_arm
```

## 3. GitHub Actions例（.github/workflows/arm64_test.yml）
```yaml
name: ARM64 OS Test
on:
  push:
    paths:
      - 'kernel_arm/**'
      - 'userland_arm/**'
      - 'include_arm/**'
      - 'build_armtest/**'
      - 'Makefile'
      - '*.md'
  pull_request:
    paths:
      - 'kernel_arm/**'
      - 'userland_arm/**'
      - 'include_arm/**'
      - 'build_armtest/**'
      - 'Makefile'
      - '*.md'
jobs:
  build-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install build tools
        run: sudo apt-get update && sudo apt-get install -y gcc make
      - name: Build all tests
        run: |
          cd build_armtest
          make
      - name: Run all tests
        run: |
          cd build_armtest
          for f in *test*; do echo ">>> $f"; ./$f; done
```
