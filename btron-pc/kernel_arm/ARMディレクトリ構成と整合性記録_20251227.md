# B-Free ARM ディレクトリ構成と整合性記録（2025-12-27）

## 1. 目的
- ARM対応の本体・ドライバ・ユーザランドを、共通部分と分離しつつ一貫性・拡張性を持って管理する。

## 2. 推奨ディレクトリ構成
- kernel/（共通カーネルロジック）
- kernel64/（x86_64固有）
- kernel_arm/
  - boot/（ARM起動コード）
  - arch/（CPU依存部）
  - mm/（メモリ管理）
  - drivers/（ARMカーネル内ドライバ）
- drivers/（共通ドライバ）
- drivers_arm/（ARM専用ドライバ）
- include/（共通ヘッダ）
- include_arm/（ARM専用ヘッダ）
- userland/（共通ユーザ空間アプリ）
- userland_arm/（ARM専用アプリ・テスト）

## 3. 初期ファイル例
- kernel_arm/boot/start_arm.S … ARM起動アセンブラ雛形
- kernel_arm/arch/cpu_arm.c … ARM CPU依存部
- kernel_arm/mm/mm_arm.c … ARMメモリ管理
- kernel_arm/drivers/timer_arm.c … ARMタイマドライバ
- include_arm/types_arm.h … ARM用型定義
- drivers_arm/uart_arm.c … ARM UARTドライバ
- userland_arm/hello_arm.c … ARM用ユーザランドサンプル

## 4. 整合性のポイント
- 共通部分はbtron-pc直下やkernel/、include/に集約
- アーキテクチャ固有部分は「*_arm」「*_64」などで分離し、ビルドや管理を明確化
- サンプルやテストもuserland_arm等で分離し、混在を防止
- ドキュメントも「設計思想・進捗記録」などで共通・ARM個別を明示
