# B-Free 64/ARM GUI基本計画（2025-12-27）

## 1. 目的
- x86_64/ARM両対応のGUIシステムを実装し、将来のスマホ等も視野に入れた拡張性を確保する。

## 2. 設計方針
- GUIロジック（ウィジェット管理・イベント分配・レイアウト等）はCで共通化
- 低レベル描画・デバイス制御はアーキテクチャごとに分離（関数ポインタ/抽象化層）
- ウィジェットは構造体＋関数ポインタで拡張性を持たせる
- 入力イベント（マウス・タッチ・キー）は共通構造体で扱う
- ARM移植時はタッチ・高DPI等も考慮

## 3. 実装機能（優先順）
1. ウィンドウ（複数、移動・サイズ変更）
2. ボタン（クリック検出、ラベル表示）
3. マウス対応（座標取得、クリック・ドラッグ検出）
4. テキスト表示・入力（ラベル、テキストボックス）
5. リストボックス
6. スクロールバー
7. メニュー、チェックボックス、ラジオボタン、画像表示、ダイアログ等
8. フォーカス管理、イベント処理、再描画、レイアウト管理

## 4. ファイル構成
- gui_common.h ... 共通インターフェース
- gui_x86_64.c / gui_arm.c ... アーキテクチャ依存部
- gui_widget.h / gui_widget.c ... ウィジェット管理
- gui_sample.c ... サンプル実装

## 5. 今後の拡張
- タッチUI、ジェスチャ、IME、アクセシビリティ
- アプリ間通信、ウィンドウマネージャ
- 高DPI/多解像度対応
