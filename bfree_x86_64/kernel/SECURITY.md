# B-Free x86_64 カーネル セキュリティ・権限管理方針

## 目的
- カーネル/ユーザー空間分離
- /dev, /sys, /proc等のアクセス制御
- デバイス・システムリソースの保護

## 基本方針
- すべてのカーネルAPIはアクセス権限チェックを実装可能な構造とする
- ユーザー空間からの直接アクセスはディスパッチ層で検査
- デバイスごとにアクセス権限（例: 読み/書き/管理）を設定
- プロセスごとに権限レベル（root, user, guest等）を管理
- 今後、認証・認可・監査APIを段階的に拡張

## 実装例（予定）
- devfs_dispatch/sysfs_dispatch/procfs_dispatchで権限チェック関数をフック
- プロセス情報に権限レベルを保持
- 不正アクセス時はエラーを返す
