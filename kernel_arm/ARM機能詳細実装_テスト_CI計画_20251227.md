# ARMカーネル各機能 詳細実装・テスト・CI対応計画（2025/12/27）

## 1. 詳細実装方針
- 各API雛形（割り込み・MMU・プロセス・FS・ネットワーク等）を順次詳細化
- 仕様・設計・実装・テスト・ドキュメントを各ファイル/ディレクトリで管理
- サンプル/テストコードはuserland_arm/配下に追加

## 2. テスト方針
- 各機能ごとに単体テスト（C関数単位）をuserland_arm/で実装
- シェルから各APIを呼び出すコマンドも追加
- テスト結果・課題は進捗記録ファイルに随時反映

## 3. CI対応方針
- Makefileにテストターゲット追加（例: make test_arm）
- GitHub Actions等でクロスビルド・QEMU自動テストを将来的に導入
- テストログ・ビルドログを保存
