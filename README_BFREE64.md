B-Free OS 64ビット版は、BTRONの設計思想を現代のx86-64環境で再現・発展させることを目指したプロジェクトです。

- マイクロカーネル構造
- POSIX/UNIX親和性
- 「動く・使える・拡張しやすい」を重視

## 起動方法（例: QEMU）

```
powershell -ExecutionPolicy Bypass -File run_bfree64_qemu.ps1
```

## 特徴
- 64ビットカーネル・ブートローダ
- シンプルなシェル・コマンド群
- 段階的な機能拡張と記録重視の開発
