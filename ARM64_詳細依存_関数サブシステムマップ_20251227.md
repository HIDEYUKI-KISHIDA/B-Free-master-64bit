## 2. サブシステム・レイヤー間呼び出し例

- [ユーザーランド] → [APIヘッダ] → [カーネル実装]
  - 例: api_sample_arm.c → net_api_arm.h → net_arm.c
- [カーネル] → [デバイスドライバ] → [型定義]
  - 例: net_arm.c → device_arm.c → types_arm.h
- [ユーザーランド/カーネル] → [デバッグAPI]
  - 例: debug_test_arm.c, debug_arm.c → debug_arm.h
